This is a proposal to allow field extensions. There used to be [spec edits](https://github.com/graphql/graphql-spec/pull/1196) but as it seemed hard to merge, it is moved to a GAP. The matching [graphql-spec issue](https://github.com/graphql/graphql-spec/issues/1162) is still active. Feel free to comment there or open a PR to this GAP.

This is currently implemented in Apollo Kotlin.
